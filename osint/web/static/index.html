Passive and active enumeration with optional port scanning and local exploit-reference lookup.

Scan

Modules

Passive: no requests are sent to the target; sources may be public or local.

Active: contacts the target directly and appears in its logs.

Advanced

Header values are not included in reports. Host, Content-Length, Transfer-Encoding, Connection, and User-Agent cannot be overridden here.

SearchSploit searches the local Exploit-DB database and displays references automatically when enumeration detects software banners. It does not run exploits. RustScan performs active port scanning and requires explicit authorization.
